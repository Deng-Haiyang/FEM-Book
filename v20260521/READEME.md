# 三维空间桁架有限元分析程序

> 三维杆单元（空间桁架）的刚度矩阵、应力计算与整体桁架求解  
> 纯 Python + NumPy 实现，适用于教学与小型结构分析

## 功能一览

- ✅ 计算三维杆单元长度、方向余弦  
- ✅ 生成全局坐标系下的 **6×6 单元刚度矩阵**  
- ✅ 根据节点位移计算 **轴向应变、应力、轴力**  
- ✅ 自动检验刚度矩阵的 **对称性、半正定性、秩、奇异性**  
- ✅ 验证 **刚体平移** 产生零内力的物理性质  
- ✅ 验证刚度矩阵 **第 j 列的物理意义**（单位位移引起的节点力）  
- ✅ **多单元组装** 形成整体刚度矩阵  
- ✅ **约束处理** 与 **整体桁架求解**（节点位移、支反力、各杆内力）  
- ✅ 内置两个验证算例 + 一个空间桁架实例，可直接运行

## 快速开始

### 1. 运行全部内置算例

```bash
python truss3d.py
```

程序会自动执行：
- 算例1：沿 x 轴的一维杆单元  
- 算例2：空间任意方向杆单元  
- 退化单元检测  
- 附加题：4 节点空间桁架整体求解

### 2. 在自己的代码中使用

```python
import numpy as np
from truss3d import (
    truss3d_element_stiffness,
    truss3d_element_stress,
    solve_truss3d,
    node_dof
)

# --- 单个单元刚度矩阵 ---
x1 = [0, 0, 0]
x2 = [1, 2, 2]
E, A = 210e9, 2e-4
L, c, Ke = truss3d_element_stiffness(x1, x2, E, A)

# --- 应力计算 ---
de = [0, 0, 0, 1e-3, 2e-3, 2e-3]   # 节点位移 (m)
epsilon, sigma, N = truss3d_element_stress(x1, x2, E, A, de)

# --- 整体桁架求解 ---
nodes = np.array([[0,0,0], [1,0,0], [0,0,1]])
elements = [
    [0, 1, 210e9, 1e-4],
    [0, 2, 210e9, 1e-4]
]
loads = np.zeros(9)
loads[node_dof(2, 'z')] = -1000.0        # 节点2施加-z方向力
fixed_dofs = [
    node_dof(0, 'x'), node_dof(0, 'y'), node_dof(0, 'z')
]

results = solve_truss3d(nodes, elements, loads, fixed_dofs)

print("节点位移 U:\n", results["U"])
print("支反力 R:\n", results["reactions"])
print("杆件结果:", results["element_results"])
```

## 核心函数说明

| 函数 | 作用 | 返回值 |
|------|------|--------|
| `truss3d_element_stiffness(x1,x2,E,A)` | 计算单元长度、方向余弦、6×6 刚度矩阵 | `L, c, Ke` |
| `truss3d_element_stress(x1,x2,E,A,de)` | 根据单元节点位移计算应变、应力、轴力 | `epsilon, sigma, N` |
| `check_stiffness_properties(Ke)` | 检查对称性、特征值、秩、奇异性 | `dict` |
| `rigid_translation_check(Ke)` | 验证刚体平移是否产生零内力 | `dict` |
| `assemble_global_stiffness(nodes, elements)` | 组装整体刚度矩阵 | `K (ndarray)` |
| `solve_truss3d(nodes, elements, loads, fixed_dofs)` | 求解整体桁架（位移、反力、单元结果） | `dict` |
| `node_dof(node_id, direction)` | 返回节点某个自由度的全局编号 | `int` |

## 注意事项

- **单位制**：建议统一使用 **N, m, Pa**（即长度 → 米，力 → 牛顿，弹性模量 → 帕斯卡）。  
- **节点编号**：从 0 开始。  
- **约束自由度**：使用 `node_dof()` 生成，例如 `node_dof(0, 'x')` 表示节点 0 的 x 方向自由度。  
- **退化单元**：若两节点坐标相同，程序会抛出 `ValueError`。  
- **机构检测**：若整体刚度矩阵的自由自由度部分奇异，程序会报错“约束不足或结构存在机构”。
